# Radial Medicine Menu

![alt text](https://github.com/shrbyte/PZmod_RadialMedicineMenu/blob/master/image.jpg "Preview")

Project Zomboid B41 Mod.<br>
https://steamcommunity.com/sharedfiles/filedetails/?id=2937217327<br>

This mods adds radial medicine menu.<br>
Each category of the menu, and the menu as a whole, becomes available if the character has a corresponding wound, pills in the inventory, or a bandage applied.

### How to use:
Just hold the "**Z**" key (by default) or D-Pad Down if you're using controller.<br>
If any options are available for your character, the radial menu will open.

### NOTES:
* Holding/pressing the menu key can be toggled in the mod's settings. \*
* You can change the key in the control settings under the "UI" category. \*
* When playing on a standard key laying if you are near/inside the car, to open a radial menu, you will just have to close the selection menu of the seat without releasing the key.<br>
\* - **requires "ModOption"**.

### Compatibility
* At the moment, the mod does not overwrite the basic game functionality, except <code>ISDPadWheels</code> for gamepad compatibility.
* Should be compatible with any mod.
* The exception is "**Immersive Medicine**" mod - however, there should be no errors, just part of its functions will not be available in the radial menu.
